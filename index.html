    Lab manual

    Aim: To simulate FCFS, SJF, SRTF, Priority, Round Robin and Multi-Level Feedback Queue scheduling, draw the Gantt chart, and find completion, turnaround and waiting times.

    Turnaround Time = Completion Time - Arrival Time
Waiting Time    = Turnaround Time - Burst Time
CPU use         = busy time / total time

    FCFS and SJF and Priority here are non-preemptive. SRTF is the preemptive form of SJF. MLFQ has Q0 (quantum 2), Q1 (quantum 4) and Q2 (FCFS). A process that uses its full slice moves down one queue, and a waiting process in a higher queue preempts a running one.

    FCFS:     run ready processes in order of arrival
SJF:      when CPU is free, pick ready process with smallest burst
SRTF:     every time unit, run the ready process with least remaining time
Priority: when CPU is free, pick ready process with best (lowest) priority number
RR(q):    queue = ready processes
          loop: p = dequeue(); run min(q, p.remaining)
                add new arrivals to queue; if p not finished enqueue(p)
MLFQ:     run first process of highest non-empty queue
          if it used its whole quantum: demote one level
          if a higher queue becomes non-empty: preempt

for each process:
    CT = time it finished
    TAT = CT - AT;  WT = TAT - BT
    #include <stdio.h>
/* FCFS: processes entered in arrival order */
int main(void) {
    int n, at[20], bt[20], t = 0;
    float sw = 0, st = 0;
    printf("Number of processes: ");
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        printf("P%d arrival and burst: ", i + 1);
        scanf("%d %d", &at[i], &bt[i]);
    }
    printf("PID AT BT CT TAT WT\n");
    for (int i = 0; i < n; i++) {
        if (t < at[i]) t = at[i];          /* CPU idle */
        t += bt[i];
        int tat = t - at[i], wt = tat - bt[i];
        printf("P%d  %d  %d  %d  %d  %d\n", i + 1, at[i], bt[i], t, tat, wt);
        st += tat; sw += wt;
    }
    printf("Avg TAT = %.2f  Avg WT = %.2f\n", st / n, sw / n);
    return 0;
}

    What is the convoy effect? Short processes wait behind one long process in FCFS, so average waiting time rises.

    Which algorithm gives the lowest average waiting time? SRTF (and SJF when all arrive together) is optimal, but it needs burst times in advance and can starve long jobs.

    How does the RR quantum matter? A huge quantum behaves like FCFS. A tiny one wastes time on context switches.

    What is starvation, and how is it fixed? A process waits forever because others always win. Aging, which slowly improves its priority, fixes it.

    Why use MLFQ? It favours short and interactive jobs without knowing burst times.

    Monolithic kernel: the scheduler, file system, drivers and memory manager all run in kernel space as one program. Fast because calls are direct, but one faulty driver can crash the system. Examples: Linux, classic UNIX, MS-DOS.

    Microkernel: only IPC, basic scheduling and memory management stay in the kernel. Drivers and file systems run as user-space servers. More stable and secure, but message passing adds overhead. Examples: MINIX 3, QNX, L4, Mach.

    Layered kernel: the OS is built as layers, from hardware at layer 0 up to the user interface, and each layer uses only the one below it. Easy to debug and verify, but hard to order and slower through many layers. Examples: THE operating system, early VMS.
